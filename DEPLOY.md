## Phase 3 — You: Render (free tier)

### Option A — Blueprint (recommended)

1. [Render Dashboard](https://dashboard.render.com) → **New** → **Blueprint**
2. Connect the backend repo (Render reads `render.yaml`).
3. Review services created:
   - `aura-tech-db` (Postgres, free)
   - `aura-tech-redis` (Key Value, free)
   - `aura-tech-api` (Web Service, free, Docker)
4. Add **manual environment variables** on `aura-tech-api`:

   | Variable | Value |
   |---|---|
   | `BREVO_API_KEY` | from Brevo |
   | `BREVO_FROM_EMAIL` | your sender email |
   | `ADMIN_EMAIL` | admin inbox |
   | `CLOUDINARY_CLOUD_NAME` | from Cloudinary |
   | `CLOUDINARY_API_KEY` | from Cloudinary |
   | `CLOUDINARY_API_SECRET` | from Cloudinary |
   | `FIREBASE_SERVICE_ACCOUNT_JSON` | optional, one-line JSON |

   `JWT_SECRET` is auto-generated by the blueprint unless you override it.

### Option B — Manual setup

Create Postgres, Key Value, and Web Service (Docker) separately and copy env vars from `.env.example` production section.

### Free tier notes

| Resource | Free plan behavior |
|---|---|
| Web Service | Sleeps after ~15 min idle; cold start on next request |
| Key Value | 25 MB, persists |
| Postgres | **Expires after 30 days** on Render free DB |

> **Important:** Render’s free Postgres is **not** permanent. After 30 days you must upgrade ($6/mo Basic) or migrate to [Neon](https://neon.tech) / [Supabase](https://supabase.com) free Postgres and set `DATABASE_URL` manually.

### Custom domain

1. Web Service `aura-tech-api` → **Settings** → **Custom Domains**
2. Add `api.auratechplus.com`
3. Create DNS **CNAME** `api` → Render target hostname
4. Wait for TLS (usually minutes)

### Verify backend

```text
GET https://api.auratechplus.com/health
```

Expected:

```json
{ "status": "ok", "timestamp": "..." }
```

Check logs for:

```text
✅ PostgreSQL connected
✅ Migrations applied
✅ Redis connected
🚀 AURA TECH Backend running
```

## Phase 4 — You: Vercel (frontend)

In **Project → Settings → Environment Variables**:

```env
BACKEND_API_URL=https://api.auratechplus.com/api
NEXT_PUBLIC_SITE_URL=https://www.auratechplus.com
STOREFRONT_COMING_SOON=false
NEXT_PUBLIC_STOREFRONT_COMING_SOON=false
```

Keep existing `NEXT_PUBLIC_FIREBASE_*` values. Redeploy.

## Troubleshooting

| Issue | Fix |
|---|---|
| CORS errors | `CORS_ORIGIN=https://www.auratechplus.com` (no trailing slash) |
| 503 / fetch failed on frontend | `BACKEND_API_URL=https://api.auratechplus.com/api` on Vercel |
| Backend crash on boot | Check `JWT_SECRET` length ≥ 32, `DATABASE_URL` set |
| Redis errors | Ensure `REDIS_URL` from Render Key Value is set |
| Cold starts | Upgrade web service to Starter ($7/mo) for always-on |
| Postgres expired | Upgrade Render Postgres or migrate to Neon/Supabase |
